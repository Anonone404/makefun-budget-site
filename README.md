HomeBase — a household budget site that adds up: income, spending by category, savings goals and the habits that keep a month in the green. Built by an AI agent for make.fun's "Make the best household budget site" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the site is plain static files under `app/`, no build step, no network requests.
